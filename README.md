# Online Library Website

## About the Project
This is my third HTML project. I created a simple Online Library Website using HTML5 only.

The purpose of this project is to practice basic and advanced HTML5 elements.

## Pages Included
1. Home Page
2. Books Page
3. Book Details
4. Registration Page
5. Login Page
6. Feedback Page

## Technologies Used
- HTML5

**Note:** This project is created using HTML only. No CSS or JavaScript is used.

## HTML Topics Covered
- HTML Basic Structure
- Headings and Paragraphs
- Text Formatting
- Images and Links
- Ordered and Unordered Lists
- HTML Tables
- HTML Forms
- Input Types
- Form Validation
- Audio and Video
- Iframe
- Details and Summary
- Progress Element
- Meter Element
- Blockquote and Quote
- Superscript and Subscript
- Pre and Code
- Meta Tags
- HTML Entities
- Semantic HTML
- Accessibility Basics
- Multiple Page Navigation

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Purpose
This project helped me practice advanced HTML5 concepts and understand how to organize a multi-page library website.
